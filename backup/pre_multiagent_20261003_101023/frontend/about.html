本页面介绍 ME-AITA 教师成长智能体的定位、功能与使用方式。

平台定位

ME-AITA 教师成长智能体是河南大学面向基础教育教师专业发展建设的智能支持平台，以“学用相生 · 研创贯通”为理念，为师范生与中小学在职教师提供数字素养提升、教学设计、课堂实践、教研反思和专业成长方面的智能支持。

主要功能

  • 智能问答：基于智谱大模型，支持多轮对话、流式输出、Markdown 与数学公式显示，辅助教学设计、课例研究、教研反思等。
  • 数字素养诊断：依据《教师数字素养》（JY/T 0646—2022）五维度提供试用版基础测评，输出能力分析与发展建议。
  • 优质资源推荐：本地资源库支持按学段、学科、类别检索课程标准、数字素养材料、教学案例与 AI 教学工具指南。
  • 教师社区：本地轻量教研讨论板，支持发布教研问题、查看讨论、删除本人发布内容。

使用说明

  1. 在首页中央聊天框输入教学问题，按 Enter 或点击发送按钮即可获得智能回复。
  2. 通过右上角“会话”菜单可以新建会话、切换历史会话或删除当前会话。
  3. 从底部功能入口进入数字素养诊断与优质资源推荐。
  4. 模型生成的教案、教学建议等为辅助参考内容，请结合课程标准、教材版本与学情审核后使用。

本地部署说明

本版本为本地单机部署，所有会话、测评记录与社区帖子均保存在本机 data/meaita.db 中，不会上传到任何第三方服务器。大模型推理通过智谱 AI 官方 API 完成。
